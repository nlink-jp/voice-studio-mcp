# 朗読劇 / オーディオブック型 音声ワークフロー

物語・小説・脚本を、**ナレーター＋登場人物**による朗読劇 / オーディオブックとして
音声化する。地の文はナレーターが語り、セリフは各キャラクターが演じる。他の4
フォーマット（資料→解説音声）と違い、入力は**フィクションの原稿そのもの**で、
要点抽出ではなく**物語解析**（シーン分割・話者帰属・演出）を行う。

入力: **$ARGUMENTS**（原稿パス、任意の workspace_root / workspace_id。無ければ聞く）。

合成〜納品の共通メカニクス・台本スキーマ・話者一覧は `../_shared/` を参照:
[PIPELINE](../_shared/PIPELINE.md) /
[SCRIPT-SCHEMA](../_shared/SCRIPT-SCHEMA.md) /
[VOICE-CATALOG](../_shared/VOICE-CATALOG.md)

> このフォーマットは資料取り込み（[SOURCE-INGEST](../_shared/SOURCE-INGEST.md) の
> 要点カード）は使わない。原稿を直接、下記の物語解析にかける。

## このフォーマットの狙い

- **話者構成**: ナレーター（地の文）＋登場人物（セリフ）。人数は作品次第。
- **役割**: ナレーターは落ち着いた安定声で情景・心情の地の文を語る。登場人物は
  性別・年齢・性格に合わせ、感情表現の幅がある声を割り当てる。
- **トーン**: 作品の雰囲気に従う（緊迫・叙情・コミカル等）。演出は `intensity` /
  `speed` / `style` / `pause_after_ms` で付ける。
- **長さ**: 作品次第。`scene` が m4b の章になるため、章立て（回・場面）を意識する。

## 手順

### 1. 環境チェック
[PIPELINE P0](../_shared/PIPELINE.md#p0-環境チェックとワークスペース準備最初に必ず)。
`list_speakers` を呼び、話者の styles と `license.status` を控える。
`workspace_id` を決め、書き込める絶対パスの `workspace_root` を用意する。

### 2. 原稿を読み、物語解析（このフォーマットの核）

- **キャラクター参照資料の優先**: 作品や企画に**キャラクター参照資料**（設定資料、
  キャラクター早見表、一人称・口調・呼称の一覧など、形式は問わない）があれば
  **最初に読む**。話者帰属と声の演出を最も確実に決められる。無ければ本文から
  推定し、自信のない帰属はユーザに確認する。
- **シーン分割**: 場面転換で `scene` 番号を割り当てる（m4b では章になる）。
- **話者帰属**: 引用符のセリフごとに話者を特定する。地の文はナレーター。
- **地の文の分割**: 説明的な地の文はナレーターの発話に。長い段落は聞きやすい
  単位（~100–150 字）に区切る。短い内面の叫び（「――は？」）はキャラクターに、
  長い内的独白はナレーターに寄せると自然。

### 3. キャスティング（人間チェックポイント — 必須）
[PIPELINE P2](../_shared/PIPELINE.md#p2-キャスティング人間チェックポイント--必須)。
`casting.template.toml` を雛形に案を提示 → 承認 → `casting.toml` を書く。

- ナレーター＝落ち着いた安定声（[VOICE-CATALOG](../_shared/VOICE-CATALOG.md) の
  「司会・アンカー・ナレーター」節）。登場人物＝性別・年齢・性格に合わせ、強弱の
  必要な役は「感情表現が豊富」節の話者を優先。
- モデル名は当てにならないことがある。迷ったら `voice-studio-mcp licenses --full
  <uuid>` で説明を確認するか、P5 のオーディションで声を突き合わせる。

### 4. 発音辞書
[PIPELINE P3](../_shared/PIPELINE.md#p3-発音辞書)。登場人物名・地名・造語など誤読
しそうな固有名詞を `register_dictionary` で登録（読みはカタカナ、`accent_type` は
下がる直前のモーラ位置、0=平板）。

### 5. 台本 JSONL
`script.template.jsonl` を参考に `<workspace>/script/` へ。
[SCRIPT-SCHEMA](../_shared/SCRIPT-SCHEMA.md) 準拠。**朗読劇の演出のコツ:**

| パラメータ | 目安 |
|-----------|------|
| `intensity` (0–2) | 平常 1.0 / 抑えた語り 0.7–0.9 / 動揺・激昂 1.3–1.6 / 絶叫 1.7–2.0 |
| `speed` (0.5–2) | 地の文 0.9–1.0 / セリフ 1.0 / 緊迫 1.05–1.2 / 回想 0.85–0.95 |
| `volume` (0–2) | 相対バランスのみ（ささやき 0.6–0.8、叫び 1.2–1.5）。全体音量は master 側 |
| `pause_after_ms` | 間 300–600 / 段落 700–1000 / シーン転換 1200–2000 |

id は 10 刻み。**既存 id は絶対にリナンバーしない**（合成キャッシュとリテイクのキー）。

### 6〜9. 合成・試聴・マスタリング・納品
[PIPELINE P5–P9](../_shared/PIPELINE.md#p5-ボイスオーディション任意) に従う。
オーディオブックは `master` を `format: "m4b"`（`scene` が章になる）、配信用の
単一トラックは `"mp3"`。試聴で口調・掛け合いがズレたら `intensity`/`speed`/`style`
を調整して差分再合成、間は `pause_after_ms` で調整（再マスターのみ）。

- [ ] `scene` が場面転換・章立てに沿っているか（m4b の章になる）
- [ ] ナレーターと各キャラの声質・性別が聞き分けられるか
