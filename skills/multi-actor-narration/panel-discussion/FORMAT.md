# パネル解説型 解説音声ワークフロー

資料・テーマを **司会＋複数の専門家** による討論として音声化する。
1 つの論点を賛成・懐疑・別視点から掘り下げ、聞き手が自分で判断できるよう
バランスよく整理する。深掘りや意思決定支援に向く。

入力: **$ARGUMENTS**（資料パス or テーマ、任意の workspace_root / workspace_id。無ければ聞く）。

共通メカニクスは `../_shared/` を参照:
[PIPELINE](../_shared/PIPELINE.md) /
[SCRIPT-SCHEMA](../_shared/SCRIPT-SCHEMA.md) /
[SOURCE-INGEST](../_shared/SOURCE-INGEST.md) /
[VOICE-CATALOG](../_shared/VOICE-CATALOG.md)

## このフォーマットの狙い

- **話者数**: 3〜4 名（司会＋専門家 2〜3）。
- **役割**: 司会＝中立の進行・論点提示・要約。専門家 A/B/C＝異なる立場・
  専門分野を担当（例: 推進派 / 慎重派 / 実務・現場視点）。
- **トーン**: 落ち着いて知的。対立は扱うが、攻撃的でなく建設的に。
- **公平性**: [公平性の原則](#公平性の扱い必読)を厳守。一方に肩入れしない。
- **長さ**: 1 論点 5〜8 分、全体 15〜30 分。

## 手順

### 1. 環境チェック
[PIPELINE P0](../_shared/PIPELINE.md#p0-環境チェック最初に必ず)。

### 2. 資料を論点へ
[SOURCE-INGEST](../_shared/SOURCE-INGEST.md) で要点カード化。パネルでは
各カードの `key_point` から**対立軸のある論点**を 2〜4 個立てる。構成:

1. **導入** — 司会がテーマと「なぜ議論の余地があるか」を提示。
2. **論点ごとの討論** — 論点提示 → 専門家 A の見解 → B の反論/補足 →
   （C の別視点）→ 司会が両論を整理。これを論点数だけ繰り返す。
3. **総括** — 各専門家が一言、司会が「対立点と合意点」を整理して締める。

各論点で**必ず複数の視点を出す**。片方しか言えない論点は、反対側の
懸念や前提を司会が補う。

### 3. キャスティング（人間チェックポイント）
[PIPELINE P2](../_shared/PIPELINE.md#p2-キャスティング人間チェックポイント--必須)。
推奨: 司会=hinakoyuhara or 阿井田茂、専門家=猩々博士 / ろてじん / 花音 など
**声質を明確に分ける**（男女・年齢差）。誰の発言か聞き分けられることが最重要。
`casting.template.toml` を雛形に案提示 → 承認 → `casting.toml`。

### 4. 発音辞書
[PIPELINE P3](../_shared/PIPELINE.md#p3-発音辞書)。専門分野語が多いので入念に。

### 5. 台本 JSONL
`script.template.jsonl` を参考に。[SCRIPT-SCHEMA](../_shared/SCRIPT-SCHEMA.md) 準拠。
**討論の書き方のコツ:**

- 発言の頭に立場を滲ませる（「私は推進の立場ですが…」「一方で懸念は…」）が、
  レッテル貼りはしない。
- 反論は人格でなく論点に向ける（「その前提はこう変わり得る」）。
- 司会は各ラウンドの最後に**両論を1文ずつ**中立に要約し、`speed` 0.95。
- 白熱する場面は専門家の `intensity` を 1.3〜1.5、司会は 1.0 で場を鎮める。
- 話者交代のたび短い間（`pause_after_ms` 300〜400）。論点転換は 800＋scene 増。

### 6〜9. 合成・試聴・マスタリング・納品
[PIPELINE P5–P9](../_shared/PIPELINE.md#p5-ボイスオーディション任意)。
試聴では**声の聞き分け**を最優先で確認。近い声があれば差し替える。

## 公平性の扱い（必読）

- 政治・倫理・政策など論争的テーマは、各立場を**その支持者が最も説得的に
  述べる形**で提示する。Claude 自身の意見の表明ではなく「論者ならこう言う」
  という枠組みにする。
- どの論点も、生成した見解の後に反対視点や実証上の争点を添える。
- 極端で有害な立場（子どもの危険・標的型暴力の擁護等）は扱わない。
- 事実性チェック（[SOURCE-INGEST](../_shared/SOURCE-INGEST.md#事実性チェック必須)）
  を徹底。数値・出典の裏取りは `WebSearch` で。
