# 対談ポッドキャスト型 解説音声ワークフロー

資料・テーマを **ホスト＋ゲスト（専門家）** の自然な対談として音声化する。
ホストが聞き手を代弁して問いかけ、ゲストが噛み砕いて答える NotebookLM 風の
フォーマット。堅い資料を「ラジオで聴ける会話」に変える。

入力: **$ARGUMENTS**（資料パス or テーマ、任意の workspace_root / workspace_id。無ければ聞く）。

合成〜納品の共通メカニクス、台本スキーマ、資料取り込み、話者一覧は
`../_shared/` を参照:
[PIPELINE](../_shared/PIPELINE.md) /
[SCRIPT-SCHEMA](../_shared/SCRIPT-SCHEMA.md) /
[SOURCE-INGEST](../_shared/SOURCE-INGEST.md) /
[VOICE-CATALOG](../_shared/VOICE-CATALOG.md)

## このフォーマットの狙い

- **話者数**: 2 名（ホスト＋ゲスト）が基本。深掘りが必要なら第2ゲストを追加。
- **役割**: ホスト＝聞き手の代理（素朴な疑問・要約・進行）。ゲスト＝専門家
  （解説・具体例・脱線からの回収）。
- **トーン**: 親しみやすく、テンポよく。相槌・言い換え・たとえ話を多用。
- **長さ**: 1 トピック 3〜7 分、全体 10〜20 分が聴きやすい。

## 手順

### 1. 環境チェック
[PIPELINE P0](../_shared/PIPELINE.md#p0-環境チェック最初に必ず)。`list_speakers`。

### 2. 資料を要点カードへ
[SOURCE-INGEST](../_shared/SOURCE-INGEST.md) に従い入力を読み、要点カード化。
このフォーマットでは各カードの `listener_question` が**ホストの問い**になる。
番組の流れを組む:

1. **オープニング** — 挨拶＋今日のテーマを1〜2文で予告（フック）。
2. **本編** — 要点カードを 3〜5 個、Q&A の掛け合いで展開。1 カード =
   「ホストの問い → ゲストの解説 → ホストの要約/リアクション」の 1 ラウンド。
3. **まとめ** — ゲストが要点を3つに整理、ホストが締めの一言。

### 3. キャスティング（人間チェックポイント）
[PIPELINE P2](../_shared/PIPELINE.md#p2-キャスティング人間チェックポイント--必須)。
`casting.template.toml` を雛形に案を提示 → 承認 → `casting.toml` を書く。
推奨: ホスト=まお or hinakoyuhara、ゲスト=猩々博士 or TANAKA（明るめ）。
2 人の**声質と性別を変える**と聞き分けやすい。

### 4. 発音辞書
要点カードの `term` を [PIPELINE P3](../_shared/PIPELINE.md#p3-発音辞書) で登録。

### 5. 台本 JSONL
`script.template.jsonl` を参考に `<workspace>/script/` へ。
[SCRIPT-SCHEMA](../_shared/SCRIPT-SCHEMA.md) 準拠。**対談の書き方のコツ:**

- ホストの相槌（「なるほど」「へえ、そうなんだ」）を挟んで一方的な講義に
  しない。相槌は短く `intensity` 1.1、`volume` 0.85。
- ゲストの長い説明は 100〜150 字で切り、間にホストの合いの手を入れる。
- **たとえ話・言い換え**をゲストのセリフに入れる（「つまり〜みたいなものです」）。
- 話題転換はホストが担う（「では次に〜」）。`pause_after_ms` 800、scene を増やす。
- 数字・専門語はゲストが `speed` 0.9 でゆっくり。
- 掛け合いのテンポは `speed` 1.0〜1.05。

### 6〜9. 合成・試聴・マスタリング・納品
[PIPELINE P5–P9](../_shared/PIPELINE.md#p5-ボイスオーディション任意) に従う。
配信用は mp3。試聴で「講義っぽく硬い」と感じたら相槌を足し、間を詰める。
