# 台本 JSONL スキーマと演出パラメータ

voice-studio の script JSONL スキーマ（本サーバの `internal/script` が正本）。
全フォーマット（解説音声4種・朗読劇）で共通。1 行 = 1 発話。
ツールがスキーマを拒否したら、記憶よりツールのエラー詳細を信頼する。

```jsonl
{"id":10,"scene":1,"speaker":"司会","text":"今日のテーマは…","speed":0.98,"pause_after_ms":500}
{"id":20,"scene":1,"speaker":"解説","text":"はい、ポイントは3つあります。","style":"おちつき","intensity":1.1}
```

## フィールド

| フィールド | 必須 | 意味 |
|-----------|------|------|
| `id` | ○ | 発話の一意番号。**10 刻み**。既存 id はリナンバー禁止 |
| `scene` | ○ | シーン/章番号。m4b では章になる。トピックの切れ目で増やす |
| `speaker` | ○ | casting.toml の character 名と一致させる |
| `text` | ○ | 読み上げ文。1 発話 ~100–150 字を目安に分割 |
| `style` | 任意 | casting の styles で定義した感情名 |
| `intensity` | 任意 | 感情の強さ 0–2 |
| `speed` | 任意 | 話速 0.5–2 |
| `volume` | 任意 | **相対**バランスのみ（全体音量は master 側） |
| `pause_after_ms` | 任意 | 発話後の無音 ms |

## 演出ガイド（解説音声向けチューニング）

| パラメータ | 目安 |
|-----------|------|
| `intensity` (0–2) | 平常 1.0 / 落ち着いた解説 0.8–1.0 / 強調・熱意 1.2–1.5 / 驚き・リアクション 1.5–1.8 |
| `speed` (0.5–2) | ナレーション 0.95–1.0 / 対話 1.0–1.05 / 要点の念押し 0.9 / テンポ良い掛け合い 1.05–1.15 |
| `volume` (0–2) | 相対バランスのみ（相槌をやや下げる 0.85 等）。全体音量は `master.loudnorm_i` |
| `pause_after_ms` | 文間 300–500 / 段落・話題転換 700–1000 / シーン切替 1200–1800 |

## 解説音声ならではの間の作り方

- **問いかけ→回答**の前に 400–600ms の間を置くと「聞き手が考える時間」になる。
- **箇条書きの列挙**は各項目 `pause_after_ms` 300ms 前後で軽くリズムを付ける。
- **数字・固有名詞**は前後をやや遅く（speed 0.9）読むと聞き取りやすい。
- 相槌（「なるほど」「へえ」）は intensity 1.0–1.2、短く、`volume` 0.85 で
  主話者を邪魔しない。
