# ボイスカタログと役割別の推奨

`list_speakers`（2026-07-04 取得）のスナップショット。**実行時は必ず
`list_speakers` を叩き直して最新の uuid / style_id / license を確認する**こと。
UUID・style_id は下記のとおりだが、モデルは追加・更新される。

## ライセンス早見

| 区分 | 該当モデル例 | 配信可否 |
|------|------------|---------|
| CC0（クレジット不要） | zonoko | 商用・非商用とも自由 |
| ACML 1.0（営利可・クレジット任意） | 大半のモデル | 商用可。禁止用途(なりすまし/誹謗中傷/政治宗教/詐欺)注意 |
| ACML Non-Commercial | Shinjou Tomoharu, 天深シノ, 様子ヶ丘シイナ | **商用不可**。社内試作のみ |
| CC BY-SA 4.0 | M2 | クレジット必須＋**成果物の継承(ShareAlike)義務**。配信物のライセンス整合注意 |
| Tαkoe 独自 | 七日週_T2, 水巻咲_T2 | 著作権表示必須・宗教/ギャンブル禁止・無改変再配布禁止 |

商用配信では ACML 1.0 か CC0 を選ぶのが無難。最終判断は公開前にユーザ確認。
